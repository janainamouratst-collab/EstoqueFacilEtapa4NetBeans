# Estoque Fácil

- Java Swing
- MySQL
- JDBC
- NetBeans
- Git e GitHub

## Objetivo do software

O Estoque Fácil é um sistema desktop desenvolvido para auxiliar pequenas e médias empresas no controle de estoque. O sistema permite cadastrar produtos, consultar informações, registrar movimentações de entrada e saída e gerar relatórios para facilitar o gerenciamento do estoque.

## Funcionalidades do sistema

- Login de usuário.
- Cadastro de produtos.
- Consulta de produtos.
- Edição de produtos.
- Exclusão de produtos.
- Registro de entrada de estoque.
- Registro de saída de estoque.
- Relatório de inventário.
- Consulta de produtos com estoque baixo.
- Consulta de produtos com validade próxima.

## Banco de dados

O sistema utiliza o banco de dados MySQL e possui tabelas para usuários, produtos e movimentações de estoque.

## Como executar

1. Execute o script SQL localizado na pasta `sql`.
2. Abra o projeto no NetBeans.
3. Verifique a configuração do banco de dados no arquivo `DBConnection.java`.
4. Adicione o driver JDBC do MySQL, se necessário.
5. Execute a classe `Main.java`.

## Conclusão

O sistema Estoque Fácil está em desenvolvimento e utiliza Java, MySQL e JDBC para realizar o controle de produtos e movimentações de estoque.
