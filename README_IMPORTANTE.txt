PROJETO ESTOQUE FÁCIL - ETAPA 4

1. No MySQL Workbench, execute o arquivo sql/estoque_facil_etapa4.sql.
2. No NetBeans, abra o projeto.
3. Adicione o driver mysql-connector-j nas bibliotecas do projeto.
4. Se necessário, ajuste usuário e senha no arquivo src/estoquefacil/DBConnection.java.
5. Execute a classe principal Main.java.
